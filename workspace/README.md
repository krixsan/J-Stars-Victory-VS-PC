# anyPS4 Workspace

Direktori ini digunakan sebagai area kerja lokal untuk menempatkan file game mentah sebelum diproses oleh translation wrapper:
- File `.pkg` (PlayStation 4 Package)
- Decrypted `eboot.bin`
- Decrypted `.prx` modules (`libc.prx`, `libSceFios2.prx`, dll.)
- Folder `app0/` hasil ekstraksi

> **PERINGATAN KEAMANAN & HUKUM:**
> Folder ini dikecualikan secara ketat oleh `.gitignore`. Jangan pernah melakukan commit file game berhak cipta, dump memori, atau aset komersial ke dalam repositori Git publik.
